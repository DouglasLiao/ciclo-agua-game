# Estratégia de Uso de IA

Este documento descreve possíveis pontos de integração de IA no futuro do projeto.

## Ideias Iniciais

- Geração dinâmica de perguntas de quiz a partir de um modelo local ou API.
- Análise das ações do jogador para adaptar a dificuldade.
- Feedback textual personalizado sobre o desempenho.
